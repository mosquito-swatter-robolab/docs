# D01 문제 정의서 v2 | 불을 끈 침실에서 모기 접근 줄이기

D01 · 문제 정의서 · 작성 gm(초안 보조 Codex) · 검토 gm 예정 · 상태 초안 · 버전 v0.4 · 관련 [D02](../charter/charter.md), [D03](../requirements/requirements.md)

## 사용자와 현재 상황

- 기존 문제 제안서 [D02 팀 차터](../charter/charter.md), [이전 D01](problem-statement-v0.3.md)
- 대표 사용자는 밤에 불을 끄고 잠드는 사람이다. 실험에서는 침대에 누운 사람 모형과 주변 보호 구역을 둔다. 실제 침실에서 모기가 나타나는 빈도와 밤당 작업량은 조사하지 않았다.
- 모기가 빠르게 방향을 바꾸면 눈으로 쫓다가 놓치기 쉽고, 잠든 동안에는 직접 대응하기 어렵다. 포충등은 모기가 포집 위치까지 와야 잡을 수 있고, 베개 위치에 가시광이 더해진다. 모기향 사용을 피하고 싶다는 요구도 있었다.

## 현재 작업 흐름 (As-Is)

`① 소등 전 모기 확인 → ② 포충등을 켜거나 모기채 준비 → ③ 모기가 보이면 눈으로 추적 → ④ 닿는 곳에서 모기채 사용 → ⑤ 놓치면 다시 탐색 → ⑥ 소등 후 취침`

- 반복 구간은 ③~⑤다. 한 마리를 놓칠 때마다 반복할 수 있다. 흐름은 문제를 설명하기 위한 예시이며 실제 횟수와 소요 시간은 조사하지 않았다.
- 로봇은 ③~⑤에 해당하는 감지·추적·요격을 맡는다. 소등 후에도 센서 설정에 따라 동작하며, 시뮬레이션은 모기가 보호 구역에 처음 들어오기 전까지의 요격을 평가한다.
- 사람에게는 ①~②의 사용 여부 결정과 ⑥의 취침이 남는다. 포충등 비교군은 장치를 켠 뒤 모기가 포집 범위에 접근하는 동안 대기한다.

## 현재 불편을 보여 주는 수치

| 지표 | 현재 값과 단위 | 조사 조건 | 근거 |
|---|---|---|---|
| 모기의 보호 구역 진입 | 장치 없음 55/100회 | MuJoCo 침실, 시드 410000~410099, 회당 최대 5초 | [100시드 비교](../evidence/README.md#동일-시드-100개-비교) |
| 포충등 사용 시 진입 | 약 68/100회, 중 43/100회, 강 32/100회 | 같은 시드, 포충등 위치와 밝기는 고정하고 유인 강도만 변경 | [100시드 비교](../evidence/README.md#동일-시드-100개-비교) |
| 베개 위치의 가시광 조도 | 장치 없음·로봇 약 0.08 lx, 포충등 약 0.60 lx | 설정한 실내 배경 조도와 포충등의 거리로 계산 | [베개 조도 모델](../evidence/README.md#동일-시드-100개-비교) |
| 직접 추적·포획의 작업량 | 밤당 횟수와 작업 시간 미측정 | 야간 사용자 관찰·인터뷰 미실시 | 사용자가 설명한 상황과 불편만 반영 |

모기의 진입 횟수와 베개 조도는 시뮬레이션 값이다. 포충등 유인 강도는 모델의 입력값이며 실제 제품 성능을 보정한 값은 없다.

## 시뮬레이션에서 잴 지표

| 지표 | 측정 단위 | 측정 구간 또는 집계 방법 |
|---|---|---|
| 보호 구역 진입률 | 회/100회, % | 같은 시드의 장치 없음·포충등 3조건·UR10e 네 대를 비교한다. 회당 첫 진입을 기록한다. 내부 목표는 로봇 진입 31회 이하다. |
| 진입 전 유효 포획률 | 회/100회, % | 보호 구역 진입 전에 활성 망에 닿고 판정 조건을 충족한 로봇 시험을 센다. |
| 미결 | 회/100회 | 최대 5초 동안 첫 진입과 유효 포획이 모두 발생하지 않은 로봇 시험을 센다. |
| 베개 위치 가시광 조도 | lx | 한 회의 최대 조도를 장치 조건별로 기록한다. 모의 근적외선 조명은 가시광 추가량을 0 lx로 둔다. |
| 팔 접촉·동작 한계 위반 | 접촉 건, 위반 회 | 보호 구역 접촉과 팔 간 접촉을 각각 세고, 관절·모기채 속도 한계를 위반한 시험 수를 기록한다. |

최신 네 팔 실험은 진입 전 포획 35회, 진입 36회, 미결 29회였다. 세 결과의 합은 100회이고, 진입한 뒤 포획하는 동작은 평가 범위 밖이다. 보호 구역 접촉, 팔 간 접촉, 동작 한계 위반은 각각 0이었다. 강한 포충등보다 진입이 4회 많았고, 내부 목표에는 5회 차이가 났다. [시드별 비교 결과](../evidence/bedroom-comparison.csv)

## 동료 검토에서 받은 질문

동료 검토는 예정되어 있다. 아래 질문은 프로젝트 논의에서 나왔다.

| 받은 질문 | 반영한 내용 |
|---|---|
| 포충등보다 나은 점은 무엇인가? | 고정된 포집 위치로 모기가 오는 조건과, 팔이 예상 경로로 움직여 접근을 막는 조건을 같은 시드에서 비교한다. 진입률과 베개 위치 조도를 함께 기록한다. |
| 보호 구역에 들어왔을 때 35/36을 잡았다는 뜻인가? | 진입 전 포획 35/100과 진입 36/100을 별도로 집계한다. 진입 후 포획률은 측정하지 않았다. |
| 불을 끈 상태에서 모기를 찾고 팔이 제때 닿을 수 있는가? | 모의 스테레오 감지의 지연·누락과 팔 동작 한계를 D03에 명시했다. 실제 센서 탐지 성능과 실물 운용은 별도 검증이 필요하다. |

## 로봇이어야 하는 이유

| 확인할 질문 | 답과 근거 |
|---|---|
| 물체를 옮기거나, 이동하거나, 대상에 닿아야 하는가? | 네 팔 중 해당 구역을 담당하는 팔이 모기채 망을 예상 경로로 옮겨 움직이는 모기와 접촉해야 한다. |
| 같은 동작을 반복하는가? | 모기가 접근할 때마다 위치·속도를 추정하고, 팔이 닿을 수 있는 지점을 골라 움직인다. 실제 밤당 빈도는 조사하지 않았다. |
| 사용자에게 불편하거나 위험한가? | 소등 후 눈으로 계속 추적하거나 잠든 상태에서 대응하기 어렵다. 수면자 가까이 움직이는 팔은 접촉 위험이 있어 보호 구역과 팔 사이의 접촉을 별도로 평가한다. |
| 앱, 센서 또는 고정 장치로 어느 범위까지 해결할 수 있는가? | 앱과 센서는 위치를 알려 줄 수 있고, 포충등은 포집 위치에 들어온 모기를 잡을 수 있다. 로봇의 추가 기능은 예상 경로에 모기채를 능동적으로 보내는 것이다. 포충등 대비 진입률 우위는 아직 실험으로 확인하지 못했다. |
