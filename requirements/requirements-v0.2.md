# D03 요구사항 명세 — 스테레오 요격 데모

D03 · 3일차 · 작성 gm(초안 보조 Codex) · 검토 gm 예정 · 상태 초안 · v0.2 · 관련 R-01~R-06 / T-01~T-06

| ID | 요구사항 및 수치 | 확인 |
|---|---|---|
| R-01 | 고정 카메라 2대에서 각각 1920×1080 px, 수직 시야각 45°로 관측한다. 같은 관측 틱의 유효한 픽셀 쌍에서 월드 위치(m)와 이후 속도(m/s)를 추정한다. | T-01 |
| R-02 | 물리 스텝 2 ms, 카메라 관측 간격 10틱(20 ms), 에피소드 상한 600틱(1.2 s)을 사용한다. | T-02 |
| R-03 | 조준은 영상에서 추정한 위치·속도와 팔 상태를 입력으로 사용한다. 비교용 NullAim은 조준 명령을 내지 않는다. | T-03 |
| R-04 | 명중 판정은 같은 스코어링 박스 반치수 `(0.04, 0.04, 0.003) m`를 사용한다. 인접 물리 틱 사이에 교차가 처음 있으면 명중 틱을 기록한다. | T-04 |
| R-05 | 비교군은 동일 시드와 장면을 사용한다. 시드별 명중·잠금·종료 틱, 조건별 명중률과 Wilson 95% 구간, 쌍별 단독 명중 수를 남긴다. | T-05 |
| R-06 | 공식 인수의 Wilson 명중률 하한은 **미정**이며 gm이 개발 결과를 참고해 첫 전용 시드 실행 전에 결정 문서로 확정한다. 같은 시드에서 파이프라인과 NullAim의 명중률·Wilson 구간, 양쪽 단독 명중 수, 정확한 양측 McNemar p값, 차이와 짝 부트스트랩 구간을 보고한다. 파이프라인 단독 명중이 더 많아야 하며, 정확한 양측 McNemar p값의 유의 판정은 decision 009의 비교 규칙 1과 decision 020의 사전 지정 우월성 주장에 대한 Holm 보정 규칙 3을 따른다. 부트스트랩 구간은 차이 설명용이며 판정하지 않는다. | T-06 |

20 ms는 시뮬레이션 시간 기준이다. 통합 설계의 120 fps와 카메라 16대는 가정값이다.

## 명중 판정 함수

```text
모기와 파리채의 초기 상태를 얻는다.
틱 1부터 600까지:
    모기와 팔을 한 스텝 진행한다.
    이전·현재 모기 위치, 이전·현재 파리채 자세, 박스 반치수를 swept_hit에 전달한다.
    교차가 있으면 명중과 현재 틱을 기록하고 종료한다.
마지막 틱까지 교차가 없으면 미명중을 기록한다.
```

시뮬레이터의 모기 위치는 장면 생성과 위 판정에 사용한다. 조준 모듈에는 영상 기반 추정치를 전달한다.
