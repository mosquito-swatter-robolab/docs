## 실행 기록

- 환경은 Windows, Python 3.12.14, MuJoCo 4.0.1이다. 네 팔 기본 비교는 동결한 `clearance` 실행을 기준으로 하며, 추출에 사용한 기록은 [원본 식별값](../evidence/README.md#원본-식별값)으로 구분한다.
- 같은 시드를 쓴 장치 없음, 포충등 약·중·강, 네 팔의 500개 저장 행을 대조했다. [시드별 결과](../evidence/bedroom-comparison.csv) · [410042 재생 결과](../evidence/pillow-clearance-410042.json)
- 확인할 변형은 정상 망 교차, 경계 근접 빗나감, 관측 지연, 네 팔 전체의 운동 감사, 머리맡 명령 거부, 최초 진입과 500틱 미결이다.
- 침실 회귀 테스트 13개가 통과했다. 비교 CSV에서 조건별로 시드 100개와 최초 진입을 확인하고, 재생 JSON에서 410042의 이격과 접촉 기록을 확인할 수 있다.

기존 진입 36회를 원래 5초 상한까지 이어서 돌린 별도 진단에서는 추가 포획·재이탈이 각각 0회였다. 이 진단은 R-03의 최초 진입 집계를 바꾸지 않는다. [진입 후 진단 기록](../evidence/post-entry-36.csv)
